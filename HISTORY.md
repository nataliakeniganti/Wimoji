# History

Wimoji began as a project to make vector emoji easy to browse, customize, and
use across websites and applications. Its development grew from a browser-based
studio into a project that also provides generated asset collections and a CLI.

- **4 October 2026** — Wimoji development began.
- **15 November 2026** — The upcoming Wimoji 1.0 release was announced on the [Wimoji blog](https://milanszulc.blogspot.com/2026/11/wimoji-100-is-coming-soon-on-november.html).
- **16 November 2026** — Automated SVG and PNG generation workflows were added, alongside the Wimoji CLI for retrieving icons as SVG.
- **17 November 2026** — The website deployment workflow was added to publish the app with GitHub Pages.
- **19 November 2026** — The generated catalog expanded to include monochrome outline SVG and PNG assets, and work began on generating emoji fonts.
- **20 November 2026** — Wimoji 1.0.1 was released as the project's initial public release.
